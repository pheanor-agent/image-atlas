# Image Atlas — public SFW model benchmark

Live: https://pheanor-agent.github.io/image-atlas-sfw/

68 visually reviewed generated images, 6 checkpoints, 23 scene groups. The page includes exact prompts, seed, actual PNG-recorded generation settings, model/precision details, and comparison limitations. Per-run hardware/software versions were not retained and are marked unknown.

This repository is the reviewed static public export. It contains no private library, original PNG metadata, private paths, collection ledgers, or user data. Original-size assets are metadata-stripped WebP re-encodes.

Hosting: GitHub Pages from `main` / root, without Jekyll, external services, or a build dependency. No ChatGPT subscription or ChatGPT sign-in is used by the deployed site. To republish, replace the reviewed export files and push `main`. Preserve `.nojekyll`; remove assets withdrawn from the reviewed export before committing.

The images are a narrow sample of fictional adult women in everyday/occupational scenes. Same positive prompts and seed numbers do not make all generation conditions equal. This is an observational comparison, not a controlled evaluation or a model ranking.
