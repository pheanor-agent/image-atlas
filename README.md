# Image Atlas

[Explore the gallery](https://pheanor-agent.github.io/image-atlas/)

Compare image models through matching scenes and recorded generation settings. Choose a scene, inspect each model’s result, and use side-by-side or blind comparison with synchronized zoom.

The collection contains 68 images, 6 model checkpoints, and 23 scene groups. The site explains prompts, seed, sampling settings, resolution, precision, and the limits of this sample. Some historical hardware and software details are unavailable and marked unknown. This is an observational comparison rather than a general model ranking.

Images at original resolution are provided as WebP versions.
